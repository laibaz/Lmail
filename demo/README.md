# Demo data

`lmail-contacts.csv` — 30 fake contacts (all `@example.com`) split across two
test accounts, `account-a` and `account-b`. Import via Contacts → Import in
the LMAIL UI to populate the "Account A" / "Account B" segments.

## Emails

`emails/welcome.html` — the LMAIL welcome email (uses Mautic tokens `{contactfield=firstname}` and `{unsubscribe_text}`).
