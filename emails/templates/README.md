# LMAIL email templates

Starter designs built by `scripts/build-email-templates.py`:

- `welcome.html`
- `newsletter.html`
- `sale.html`
- `product-launch.html`

The brand names and wording inside are sample content. Each uses the Mautic tokens
`{contactfield=firstname}` and `{unsubscribe_text}`.

To use one in LMAIL: create a new email, choose the Code Mode theme, and paste the file
contents into the editor.
